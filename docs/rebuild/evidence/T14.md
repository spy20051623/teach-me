- 用户默认目录最后一个启动 PID 25660 只有 startup/show，没有 shutdown/will-quit，检查时进程已不存在。Windows Application 错误日志未发现对应崩溃，无法根据缺少日志断言是原生崩溃、外部结束还是其他退出。
